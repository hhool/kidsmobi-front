# balancebiketoddler.com 外链建设清单（DR 20–60 目标）

> 生成日期：2026-10-15
> 用途：链接建设（outreach）目标池。DR = Ahrefs Domain Rating，20 < DR < 60 为目标区间。
> 重要：本表 DR 为**按垂类经验估算**，落地前请用 Ahrefs / Semrush 复核真实区间（付费指标，无法在此实时查证）。

## 一、现有外链怎么取到权威清单

公开网络检索未发现第三方页面引用本站（返回均为 WHOIS/域名工具页），符合新站特征（自然外链≈0）。权威取数途径：

1. **Google Search Console**（最权威，你自己的站）：左侧 *Links → External links → Top linking sites / Top linked pages*，可下载 CSV（上限 1000 条）。
2. **Ahrefs 免费反链检查器**：`ahrefs.com/backlink-checker` 输入域名，看前 100 条 + 各站 DR。
3. **Semrush Backlink Analytics**：竞品/自身反链、锚文本、dofollow 占比。
4. **Bing Webmaster Tools**：*Reports & Tools → Inbound Links*，免费且独立索引，能补 GSC 盲区。
5. 可选：把 GSC 导出的 CSV 丢给我，我写个脚本解析成“来源域 / 锚文本 / 目标页”三列清单。

## 三、优先级建议

1. **强相关 + 已覆盖平衡车**的 5 个站（#1 #2 #4 #5 #6 #20）最先触达——它们已经在写平衡车，接受“数据/专业视角补充”或互链的概率最高，且主题高度契合，链接质量最好。
2. **地区亲子杂志网**（#12–#17）：同一模板多家分站，批量投稿 ROI 高，DR 稳定在 35–50。
3. **幼儿活动/早教博客**（#8–#11）：受众=学步期父母，与“适龄平衡车”意图（站内核⼼意图）天然对齐，适合做“几岁开始骑/如何选尺寸”类客座文。
4. **HARO/引述**：低成本、常被高 DR 媒体引用的长尾渠道，建议常驻。

## 四、落地注意

- 每个目标落地前用 Ahrefs 复核真实 DR，严格筛掉 <20 与 ≥60 的。
- 优先 **dofollow**；nofollow 仅作品牌/引流，不计入 DR 目标。
- 锚文本自然分布：品牌词 + “balance bike for toddlers” + “toddler balance bike” 混合，避免锚文本过度优化。
- 不要碰付费链接农场 / 明显垃圾目录；本表目录类仅指有编辑审核的垂类/地区目录。
- 建站初期建议月增 5–10 条中质量外链，重质不重量。
