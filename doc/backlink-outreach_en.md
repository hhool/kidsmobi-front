## 3. Prioritization

1. **Strong-fit + already covers balance bikes** (#1 #2 #4 #5 #6 #20) first — they already write about balance bikes, so accepting a data/expert-angle supplement or link swap is most likely; topical match is best, link quality highest.
2. **Regional parenting magazine network** (#12–#17): same template across editions → batch guest posts, high ROI, DR steady 35–50.
3. **Toddler-activity / early-ed blogs** (#8–#11): audience = toddler parents, naturally aligned with the site's core "age-by-age" intent; good for "what age / how to size" guest posts.
4. **HARO/quote**: low-cost, long-tail channel frequently picked up by high-DR media; keep a standing pitch.

## 4. Execution notes

- Confirm real DR in Ahrefs before each outreach; strictly drop <20 and ≥60.
- Prefer **dofollow**; nofollow only for brand/traffic, not counted as DR target.
- Natural anchor mix: brand + "balance bike for toddlers" + "toddler balance bike"; avoid over-optimized anchors.
- Avoid paid link farms / obvious spam directories; "directory" here means editorially-reviewed niche/regional directories only.
- Early stage: aim for 5–10 quality links/month — quality over quantity.
